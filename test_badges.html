Badge Legend

  • Purple "Yours": Prompt created by you
  • Green "Team": Prompt created by your team
  • Cyan "View": You have view-only access via sharing
  • Violet "Edit": You have edit access via sharing
  • Gray "Private": Only visible to owner and shared users
  • Emerald "Team": Visible to all team members
  • Blue "Public": Visible to all authenticated users
  • Amber "Anonymous": Warning - accessible to non-authenticated visitors
  • Indigo "Shared X": Number of users/teams with access
