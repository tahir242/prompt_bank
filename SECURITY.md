# Security Policy

## Supported Versions

We support the latest release on the default branch. Security fixes are applied only to the latest version.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

- Do not open a public GitHub issue
- Send a private report to the maintainers
- Include steps to reproduce the issue
- Include any relevant logs or screenshots

We aim to acknowledge reports within 72 hours and provide a remediation plan or fix timeline.

## Security Best Practices

- Use prepared statements for all database queries
- Validate and sanitize all user input
- Avoid committing credentials or secrets to the repository
- Rotate credentials immediately if exposed

## Contact

Please open a private report by emailing the project maintainers or using your organization security channel. If no contact is configured, create a GitHub issue asking for a security contact and we will respond with a private channel.
